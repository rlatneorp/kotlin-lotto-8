# kotlin-lotto-precourse
### 기능 요구 사항

- 로또 번호 범위 1~45까지
- 1개에 중복되지 않는 6개의 숫자를 뽑기
- 당첨은 1등부터 5등까지
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행
- 로또 1장의 가격은 1,000원
- 당첨 번호와 보너스 번호를 입력받기
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

### 입출력 요구 사항

1. 로또 구입 금액 입력, 1000원으로 나누어 떨어지지 않으면 예외처리
2. 당첨 번호 입력 받기, 쉼표로 구분
3. 보너스 번호 입력 받기
4. 발행한 로또 수량과 번호 출력, 오름차순 정렬
5. 당첨 내역을 출력
6. 수익률은 소수점 둘째 자리에서 반올림
7. 예외 상황 시 에러 문구 출력, [ERROR]로 시작해야한다

### 요구사항 종합하여 설계

로또 구매 금액 입력 받고 변수에 저장 → 

1000원 단위로 나눠서 몇 번의 로또를 구매할지 횟수 저장 → 

랜덤으로 로또 구매 횟수에 맞게 6자리 중복 없이 생성 후 컬렉션에 저장하기→

당첨번호 6개 입력 받은 걸 쉼표를 기준으로 구분해서 변수에 저장하기 →

보너스 번호를 입력해서 변수에 저장하기 → 

당첨 기준 적용하기 →

- 당첨번호 입력 받은 것과 랜덤으로 정해진 로또 숫자를 비교해서 같은 수만큼 반환
- 2등은 보너스 번호와 일반 번호 5개 일치시에만 반환

당첨 통계 출력하기 →

- 숫자 일치한 만큼 몇 등인지 갯수 변수에 저장
- 수익금과 구매금액을 이용하여 수익률 계산하기
- 수익률은 소수점 둘째 자리에서 반올림

### 예외들

- 구매금액
    - 로또구매 금액이 1000원 단위가 아닌 경우(예:1200,900 입력)
    - 구매금액 0원 입력
    - 구매금액 음수 입력
    - 구매금액 뒤에 ‘원’ 붙일 경우
- 당첨번호
    - 번호 갯수가 6개가 아닐 경우
    - 쉼표로 구분짓지 않을 경우
    - 0이 들어간 경우
    - 1~45사이의 숫자가 아닌 경우
- 보너스 번호
    - 한개가 아닌 경우
    - 0이 들어간 경우
    - 1~45사이가 아닌 경우
    - 당첨번호와 중복되는 숫자가 있는 경우
